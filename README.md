# Royal Tours & Travels

A modern travel and tourism booking platform built with Next.js, React, and Tailwind CSS.

## 🌍 About
Royal Tours & Travels is a professional tourism website featuring curated travel packages, destination guides, booking management, and customer reviews. Built with modern web technologies for optimal performance and user experience.

## 📁 Project Structure

```
royaltoursandtravels/
├── app/                    # Next.js App Router
├── components/             # React Components
├── lib/                    # Utility functions
├── public/                 # Static assets (images)
├── styles/                 # Global styles
├── package.json           # Dependencies
└── next.config.js         # Next.js configuration
```

## 🛠️ Technologies Used
- **Next.js** - React framework
- **React** - UI library
- **Tailwind CSS** - Styling
- **JavaScript/TypeScript** - Programming
